# MACH’S – öffentliche App-Updates

Dieses Repository enthält ausschließlich die signierten Android-APK-Dateien und die Metadaten für den MACH’S-Updater.

- `latest.json` beschreibt die neueste Version und enthält deren SHA-256-Prüfsumme.
- `machs-v<versionCode>.apk` ist die passende Android-Installationsdatei.
- Der Quellcode, die Signaturschlüssel und persönliche Aufgaben gehören **nicht** hierher.

Neue Versionen werden erst veröffentlicht, wenn im privaten MACH’S-App-Projekt der Berechtigungsschlüssel `MACHS_UPDATES_TOKEN` für dieses Repository eingerichtet wurde.

Eine APK niemals aus unbekannten Quellen installieren.
